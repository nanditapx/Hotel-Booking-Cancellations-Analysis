# 🏨 Hotel Booking Cancellation Analysis

## 📌 Project Overview
This project focuses on analyzing hotel booking data to understand booking cancellations, customer preferences, guest types, and hotel performance.

The analysis is performed using **Microsoft Excel**, with Pivot Tables and an interactive dashboard to transform raw booking data into meaningful insights.

## 🎯 Project Objectives
- Analyze hotel booking cancellation patterns.
- Compare City Hotel and Resort Hotel bookings.
- Understand cancellation trends across different months.
- Analyze guest types and their booking behavior.
- Identify room assignment and reservation status patterns.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Dashboard
- Data Analysis & Visualization

## 📊 Key Analysis
The project includes:
- **Guest Type Analysis:** Single, Couples, and Family bookings.
- **Hotel Type Analysis:** City Hotel vs. Resort Hotel.
- **Monthly Cancellation Analysis:** Month-wise booking cancellations.
- **Room Status Analysis:** Desired and undesired room assignments.
- **Booking Performance:** Total bookings and cancelled bookings.

## 📈 Dashboard Insights
The dashboard provides a visual overview of:
- Total bookings by hotel type.
- Cancelled bookings by hotel type.
- Monthly cancellation trends.
- Guest type distribution.
- Room assignment status.

## 📁 Project Structure
- `Hotel Booking Cancellation Project.xlsx` – Excel workbook containing the dataset, Pivot Tables, and Dashboard.

## 💡 Key Learning Outcomes
- Data organization and analysis using Excel.
- Creating and managing Pivot Tables.
- Building interactive dashboards.
- Identifying trends and patterns in booking data.
- Converting raw data into meaningful business insights.
